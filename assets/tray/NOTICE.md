# Windows XP Luna notification-area chevrons

Original Microsoft graphics extracted from the Windows XP `luna.msstyles` file:
https://github.com/robberphex/docker-wine-coolq/blob/master/luna.msstyles

The `BLUE`, `HOMESTEAD` and `METALLIC` resources supply the blue, olive and silver
themes. Each PNG contains the original `TRAYCHEVRONHORIZONTAL_BMP` and
`TRAYCHEVRONHORIZONTALOPEN_BMP` strips side by side. Each button state is
19 × 20 pixels; no pixels are redrawn or scaled. The BMP alpha channel and
magenta transparency key are preserved when converting to PNG.

Columns: collapsed, expanded. Rows: normal, hot, pressed.

The resource names, source SHA-256 and output sizes are recorded in
`../sources.json`. Original graphics: Copyright Microsoft Corporation.
